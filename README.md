# Proyecto de siniestros viales de 2021
Este proyecto describe la distribución horaria de los siniestros registrados por CONASET y analiza tipos y causas dentro del tramo con más registros.
La fuente es la capa de siniestros geocodificados de CONASET, atribuida a Carabineros de Chile: https://mapas-conaset.opendata.arcgis.com/datasets/a1d136edbdde4252904241a5386df86d_0
La copia incluida conserva las columnas necesarias y elimina direcciones y coordenadas exactas. El diagnóstico original se documenta en la entrega 1.
Para ejecutar, instala las versiones de requirements.txt y abre S5_Notebook_Laboratorio_CDD.ipynb en esta carpeta.
Ejecuta todas las celdas en orden; el cuaderno reconstruye el conjunto explorado desde conaset_2021_extracto_minimizado.csv.
El análisis, las visualizaciones y la revisión ética se basan únicamente en los datos de CONASET.
La entrega 3 previa mantiene el análisis anterior; el historial del repositorio conserva la secuencia del proyecto.
Los conteos no son tasas de riesgo por viaje y la capa no representa necesariamente todos los siniestros ocurridos en Chile.
Rama pública de esta entrega: https://github.com/fre-caneo/Cienciadedatos/tree/Sumativa5
